# Mesh Guard 灯具守护

> 📖 **[保姆级使用教程（用户必读）](docs/用户使用教程.md)**

米家 BLE Mesh 灯具掉线自愈 Home Assistant 集成。

灯具掉线 → 自动定位供电开关按键 → 按开关型号自动执行断电重启 → 验证恢复 → 企业微信告警。全程无人值守。

## 功能特性

- **自动监测**：灯具离线事件捕获 + 防抖判定
- **三种恢复配方**：直断法 / 模式切换法 / 参数魔数法（按开关型号自动匹配，支持现场自动探型习得新型号）
- **修复时间窗**：默认每日 13:00–14:00 执行修复，可自定义多段；窗外掉线排队 + 即时通知
- **群指令立即修复（按站点）**：绑定企业微信智能机器人（长连接）后，群里 @机器人 回复「站点名称立即修复」即跳过时间窗/冷却，立即修复本站全部排队回路；站点名不匹配、裸「立即修复」一律静默不触发，多站点共群互不干扰
- **设备自动识别**：MIOT 型号段位 + 实体能力 + 命名习惯四级判据，按房间分组，支持人工增删改与自定义分类
- **接线映射向导**：灯具 ↔ 开关按键四步配对，断电验证防呆
- **上电状态批设**：灯具"断电恢复后"行为一键批量设置（默认断电记忆，修复过程客户无感）
- **维护任务系统**：验证/探型后台运行、可停止、与修复程序自动互斥抑制
- **配方库**：开关恢复方法可查阅、可手动新增（直断/下拉框/魔数三类）
- **企业微信告警**：掉线发现 / 恢复成功 / 恢复失败 / 模式还原失败 / 自行恢复，五类事件推送
- **一机一码授权**：离线激活，绑定 HA 实例指纹

## 前置依赖

1. 已刷冬瓜HAOS（或任意 HAOS/Supervised）的设备，aarch64/x86 均可
2. 已通过 HACS 安装并登录 **Xiaomi Home** 集成（xiaomi_home），米家设备经中枢网关本地接入
3. （可选）企业微信群机器人 webhook，用于告警推送
4. （可选）企业微信智能机器人（管理后台 API 模式/长连接创建），用于群里 @机器人 发"立即修复"指令

## 安装

### 方式一：HACS 自定义仓库（推荐）

1. 打开 HACS（极速版）→ 集成 → 右上角 ⋮ → 自定义仓库
2. 仓库地址填 `https://github.com/122566/light-guard`，类别选 **Integration**，添加
3. 在 HACS 中搜索 **Mesh Guard 灯具守护**，下载
4. 重启 Home Assistant

### 方式二：手动安装

将 `custom_components/mesh_guard` 目录复制到 HA 配置目录的 `custom_components/` 下，重启 Home Assistant。

## 激活

1. 安装后进入 设置 → 集成 → 添加集成 → 搜索 **Mesh Guard 灯具守护**
2. 页面显示**本机识别码**（12 位，形如 `A1B2-C3D4-E5F6`）
3. 将识别码发给卖家，换取绑定本机的**一次性授权码**
4. 输入授权码完成激活（一机一码，激活后永久有效）

## 使用

激活后左侧边栏出现「灯具守护」面板：

1. **设备识别**：扫描 → 确认灯具与开关分类（可按房间核对）
2. **接线映射**：新建回路，把灯具指派给供电的开关按键，用「验证通断」现场确认
3. **上电状态**：一键批量设置断电记忆
4. **设置**：配置企业微信 webhook（告警推送）、智能机器人 BotID/Secret（群指令立即修复）、站点名称与修复时间窗
5. **群指令**（可选）：群里 @机器人 回复「站点名称立即修复」（站点名须与本站设置完全一致）→ 立即修复本站全部排队回路；详细保姆级教程见 [用户使用教程](docs/用户使用教程.md)

之后全自动运行。未知型号开关用回路卡片上的「探型」一键习得。
